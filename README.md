# Telegram‑Like Android App (Kotlin + Jetpack Compose)

این مخزن یک نمونهٔ ساده از برنامهٔ پیام‌رسان شبیه به تلگرام را با استفاده از **Kotlin**, **Jetpack Compose**, **Material 3**, **Room**, **ViewModel** و **Coroutines** فراهم می‌کند.

## 📦 محتویات پروژه
- **Activities** : `LoginActivity`, `MainActivity`
- **ViewModel** : `LoginViewModel`, `MainViewModel`
- **Repository** : لایهٔ میانی برای دسترسی به دیتابیس
- **Room** : `AppDatabase`, `MessageDao`, `UserDao`
- **Compose UI** : `LoginScreen`, `MainScreen` + کامپوننت‌های پیام
- **Gradle** : تنظیمات کامل برای Android 13 (SDK 34) و Compose
- **GitHub Actions** : workflow برای ساخت خودکار APK
